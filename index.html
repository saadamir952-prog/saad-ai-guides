How it works

1. Copy a prompt — each one has its own button, or grab all 50 at once below.

2. Paste it into Claude (claude.com) — Claude builds it as an Artifact: one self-contained HTML file.

3. Make it yours — your colours, your fonts, your words.

What you need — stated honestly

These prompts work on Claude Free ($0). The free plan includes Artifacts and Sonnet, and every prompt below produces a single HTML file. No paid plan is required.

For the best results, use Opus or Fable — especially on the 20 Three.js scenes. Opus needs Claude Pro ($20/month). Fable 5.2 costs usage credits on Pro after the launch offer ends Nov 16, 2026.

Results vary. The same prompt can produce a slightly different animation each run — that is normal. If a scene looks off, run it again or ask Claude to fix the specific part that broke.

TYPE 7 prompts

Type in motion — words that move, flip, type and count.

01Kinetic TypeTYPE

Words slam in one by one with overshoot and a screen shake.

Create a single HTML file with a kinetic typography animation. On a cream background, the words "MAKE IT MOVE." slam in one word at a time — each word scales from 2.5x to 1x with a slight overshoot and a 60ms stagger, in heavy black grotesque type. Add a subtle screen shake on each landing and an orange highlight bar that sweeps under the final word. Loop every 4 seconds with a 0.8s hold. Use CSS keyframes with cubic-bezier(0.16, 1, 0.3, 1).

Dark charcoal flaps, cream letters, thin divider lines, and a subtle top-light shadow. The board cycles through three words: NOW BOARDING, ALL ABOARD, NEXT STOP.
