The idea in one sentence

Most creators guess which version of an idea will work. This method tests it: the same words, re-cut thirty ways — different hook text, different grade, different framing — posted as trial reels (shown to non-followers first, invisible on your grid) so the audience tells you which one wins before your followers ever see it.

The 5 steps

1
Record ONE strong take. One idea, thirty seconds, vertical 9:16, talking to camera. Say it once, cleanly — this single take becomes all thirty versions. The idea matters more than the polish: if the idea is weak, thirty versions of it are still weak.
2
Let Claude cut the edit. Open Claude Code, drop in the clip, and paste this prompt: 
You are my video editor. This is a 30-second talking-head clip (vertical 9:16).
1. Cut every silence longer than 0.3s and every filler word (um, uh, like).
2. Add captions: key words only, bold sans-serif, one accent word per line.
3. Add a punch-in (110-120% zoom) on the key moment.
Export as 1080x1920, 30fps, audio untouched.
Watch the result. If a cut feels wrong, tell Claude what you see and it fixes it.
3
Multiply it into genuinely different versions. Same clip, same words — but each version must change at least 3 of these 5 things: 
Make 5 genuinely different versions of this same 30-second clip. Each version must change AT LEAST 3 of these 5 things:
1. Hook text on screen (a different opening line each time)
2. Color grade (one warm, one cool, one black-and-white, one high-contrast, one faded)
3. Framing (one full frame, one 1.3x punch-in on the face, one 1.5x punch-in)
4. Caption layout (top bar, bottom bar, center-big, side pill, split screen)
5. The first 2 seconds (reorder the opening so each version starts differently)
Same words, same voice — but each version must LOOK like a different video. If two versions look alike, Instagram treats them as duplicates and shows them to nobody.
Export each as its own MP4, named version-01.mp4 ... version-05.mp4.
Run it again for more versions — five at a time is a good batch. Check them side by side: if two look alike at a glance, they are alike — change one.
4
Post them as trial reels. In Instagram, create a reel as usual — before posting, turn on Trial. (You need a public professional account with 200+ followers, or a personal account with 1,000+.) Trial reels go to non-followers first and stay off your grid, so a flop costs you nothing. Post 3–5 at a time, spaced out — never more than about 7 trial reels a day, or Instagram can pause the feature.
5
Read the results, share the winner. Wait about 24 hours for insights. Compare watch time and shares — not just views. Tap Share to everyone on the winner: it goes to your followers and your grid. The other versions stay as trials — nobody saw them, nothing to delete.

The 5 demo looks from the video

These are the five looks in the reel — each one changes hook text, grade, framing and layout at once:

  • Warm + top bar — warm grade, bold hook line in a color bar across the top.
  • Cool + bottom bar — cool grade, hook line in a dark bar at the bottom.
  • Black-and-white + center-big — monochrome, one giant word over the lower third.
  • High-contrast + side pill — punchy contrast, hook in a rounded pill at the side.
  • Faded + split screen — soft faded grade, color block filling the bottom third.

Honest limits

  • Claude Code is paid (from $17/month billed annually) — the workflow is not free as a whole.
  • Lookalikes get zero views. If two versions look the same at a glance, Instagram treats them as duplicates. Change at least 3 of the 5 axes, every time.
  • Trial reels need an eligible account — public professional with 200+ followers, or personal with 1,000+. If the Trial toggle is missing, your account does not qualify yet.
  • Don’t blast thirty at once. A handful at a time, spaced out, max about 7 a day — or the feature can pause.
  • Thirty versions of a weak idea is still a weak idea. The method finds the best version of one idea; it does not fix the idea itself.
  • It drafts, you approve. Watch every version before you post.
