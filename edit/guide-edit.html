From a Finished Video to the Beast Level.

What it is

Claude can edit videos on three levels — and each level gives you more control. Level 1: Claude edits a finished video — cuts the silences, adds music. Level 2: Claude edits on your CapCut timeline inside VS Code, without opening CapCut. Level 3 — the beast: Claude builds the whole video from code: voice, background, motion, captions — no editor needed.

This guide explains all three, with the exact tools and the honest prices. Two pieces cost money: the Claude subscription and the ElevenLabs voice. Everything else in the stack is free. Details at the end.

Level 1 — The finished video

You give Claude a video that is already shot. Claude cuts the silences and adds music — using Whisper to hear every word with the second it was said, and FFmpeg to see every frame. You get back a finished, formatted video.

The catch: the video is finished. Change one thing — one word, one cut, one music track — and you start over. Good for quick clean-ups of a video that is already good. Not for anything you will want to revise.

Level 2 — The timeline

Claude works inside VS Code, on your CapCut timeline — without opening CapCut. The timeline is a project file: Claude reads it and rewrites it. Swap any clip, move a segment, change a caption, adjust a zoom — every piece in place, and you can change anything without re-rendering the whole video.

The tool that writes CapCut project files comes from GitHub — ask Claude Code to find and install it for you. The catch: you are still doing the assembly. Claude edits the timeline, but the footage, the structure and the decisions are yours. Good for creators who already edit and want the repetitive work done for them.

How it connects: Whisper hears your words and writes each one with the second it was said. FFmpeg reads the frames. Remotion moves everything — frame by frame, it tells each element where it is. Cloudflare generates the background. ElevenLabs speaks the voiceover. Claude Code writes the Python tools and the Remotion code that tie it all together — all inside VS Code.

You do not write the code yourself. You tell Claude what you want, and Claude writes it into the project files. Claude Code is an agent, not a chatbot — you send text, it does the work.

No big software needed: you do not need CapCut, Premiere or After Effects to get a finished video — the video comes out as-is. The editor is only for more freedom and control afterwards. To change a part, tell Claude the exact second.

Heavy work needs a decent machine — on a weak laptop the rendering will be slow, and a stronger graphics card helps.

Setup order — the checklist

Do it in this order. At every step, ask Claude Code inside VS Code to do the installing for you:

  1. VS Code — free. Download and install it. This is the workspace where all the work happens.
  2. Claude Code extension — install it inside VS Code from the Extensions panel, then sign in with your Claude account.
  3. Python + libraries — ask Claude Code to install Python and the video libraries. Python has ready-made libraries for video work.
  4. Whisper + FFmpeg — the ears and the eyes. Ask Claude Code to install Whisper from GitHub and FFmpeg, so Claude can hear and see your video.
  5. Remotion — the motion. Claude Code installs the Remotion library for you.
  6. CapCut project tool — the timeline. Ask Claude Code for the GitHub project that writes CapCut timelines, so the finished edit lands on a timeline you can open and adjust.

The tools — with links

  • Whisper (OpenAI, MIT) — github.com/openai/whisper — free. Install: pip install -U openai-whisper. 99 languages, runs locally, offline.
  • Remotion — remotion.dev (GitHub: github.com/remotion-dev/remotion) — free, open-source. Code-based video: the edit is written as code, then rendered.
  • Cloudflare Workers AI — developers.cloudflare.com/workers-ai — free with a daily limit. Generates the background image.
  • ElevenLabs — elevenlabs.io — paid. The voiceover. (Our voice: Will, plain — no tags, no cloned voice.)
  • VS Code — code.visualstudio.com — free. The workspace.
  • FFmpeg — ffmpeg.org — free, open-source. Cutting, frames, loudness, muxing.
  • Claude Code — code.claude.com — paid subscription (Pro $20/month). The brain.
  • Python — python.org — free. The language the tools are written in.
