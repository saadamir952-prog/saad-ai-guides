The full guide

The rule in one line. Shoot one continuous take. Never stop the recording. When you flub a line, restart the whole sentence — never pick up mid-sentence. Claude edits from the transcript and keeps only the last version of each line.

Why it works. Claude never watches your video. It reads the transcript. When the same sentence appears three times in a row, the transcript makes the pattern obvious: attempt one, attempt two, attempt three — and only the last one is the keeper. Claude cuts the earlier versions and the pauses between them, and the take that is left sounds like you nailed it first time.

The filming checklist. (1) One continuous take — press record once, do not stop until the section is done. (2) Restart the sentence, never the recording — flub a word, pause, and say the whole sentence again from the start. (3) Never pick up mid-sentence — a half-sentence looks like a new line in the transcript, not a repeat. (4) Leave a beat between attempts — a short pause is what separates the attempts. (5) Say the sentence the same way each time — same words, same order, or it is a different line and Claude keeps both. (6) Keep going after the good one — one clean take is enough.

The mid-sentence catch. You flub the last word and restart from that word — “Claude keeps the last—” then “take.” In the transcript that reads as two fragments, not two attempts, and Claude has no clean version to keep. Restart the whole sentence instead: “Claude keeps the last—” … pause … “Claude keeps the last take.” Now there is a false start and a full clean version, and Claude keeps the clean one. If you remember one thing: restart the sentence, never the word.

Direct the edit in one-sentence commands. Say them one at a time, check the result, then give the next one: “Cut the silences.” — “Punch in on the hook.” — “Subtitles on.” Short commands keep the edit predictable: each one does one job, and if something looks wrong you know which command caused it.

The exact prompt — paste this into Claude Code.

Transcribe messy-take.mp4. For every sentence I repeated, keep only the last version of it and cut the earlier attempts. Cut the pauses between attempts. Then punch in on the hook and add word-by-word subtitles.

It says the four things Claude needs to do, in order: transcribe — keep only the last version of each repeated sentence — cut the pauses — punch in on the hook and add word-by-word subtitles. If the result keeps a repeat you wanted gone, point at it in plain words: “Cut the first two attempts of the sentence about the last take.” Claude re-cuts from the transcript — you never touch a timeline.
