# 3 Starter Prompts — How Claude Makes Motion Videos

Free from Saad AI (@saad.aig). Paste one into Claude Code, fill in the
bracketed parts, and let it write the code. Then render what it writes:
open the HTML file in a browser, or run the Remotion project. The MP4
comes out of YOUR render, not out of the model.

Full guide: https://saadamir952-prog.github.io/saad-ai-guides/motion/

---

## 1. A 3D orbit scene (Three.js, single HTML file)

> Build a 15-second 3D scene as a single HTML file using Three.js: a
> chrome torus knot rotating slowly in the centre, two thin orbit rings
> around it, warm key light, dark background. Vertical 1080×1920. The
> camera pushes in slowly the whole time. Render it to MP4.

## 2. An animated chart

> Animate this data as a 20-second chart video: [paste 4–6 numbers with
> labels]. Bars grow in one by one, the biggest number lands last with a
> count-up, clean light background, labels always readable. Vertical
> 1080×1920.
## 3. Kinetic typography explainer (Remotion)

> Make a 30-second kinetic-typography explainer in Remotion. Topic:
> [your topic]. Big bold type, one idea per shot, words landing on the
> beat, dark background, one accent colour. Vertical 1080×1920. Render
> it to MP4.

---

**Tip:** the first render is rarely the keeper. Watch it, tell Claude
what looks wrong in plain words ("the camera moves too fast", "the text
is too small"), and it patches the code. That render–review–fix loop
IS the workflow.

**Honest limit:** Claude writes code, it doesn't film. No camera, no
real footage, no photoreal people — motion graphics, 3D scenes, charts
and kinetic type. You need Claude Code (paid Claude plan) to run these.
