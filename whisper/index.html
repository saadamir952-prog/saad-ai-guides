MIT License, open-source, 112,515 stars on GitHub. Install once with pip install -U openai-whisper, run it locally — no cloud, no upload, no per-minute billing. The price is nothing, forever.

Start in 3 steps

  1. Install it — pip install -U openai-whisper (Python + ffmpeg).
  2. Run it — whisper audio.mp3 --model turbo — it writes transcript + subtitle files (.srt, .vtt, .txt).
  3. Drop the .srt into your edit — CapCut, Premiere, DaVinci or any editor. Style once, captioned in seconds.

Pick your model

Six sizes: tiny 39M, base 74M, small 244M, medium 769M, large 1550M, turbo 809M. Start with turbo — fast and near-large accuracy. Bonus: --task translate turns other languages into English (use small/medium/large for that, not turbo).
