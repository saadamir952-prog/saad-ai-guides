Claude can edit your video. It cannot hear it.

Five checks fix that. Earshot gives Claude ears: it describes a sound in words, scores it against the sound you asked for, finds the best moment in a recording, flags real vs code-made sound, and grades your whole video's audio with fixes listed worst first.

The proof, run for real on our own sound: describe → Ringtone 0.83 · match "a classic telephone ringing" → strong, z +3.8 · critique on our last video → needs work, 19/23 in range.

The cost — read this first

Earshot is free and open-source (MIT) and runs on your CPU. The one paid part is Claude Code, which needs a paid Claude plan. You need Python 3.10+ and ffmpeg. The listening models (about 1.1 GB) download once; after that it works offline.

Setup (copy-paste)

pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install "earshot[listen,mcp] @ git+https://github.com/Leonxlnx/earshot"
earshot doctor --fetch
claude mcp add earshot --scope user -e EARSHOT_THREADS=3 -- earshot mcp

The 3 commands

1. Describe — what a sound actually sounds like, not your file name:

earshot describe sound.wav

2. Match — write the sound you want; it scores strong, plausible, weak, or no match:

earshot match sound.wav "a classic telephone ringing"

3. Critique — grade the whole video's sound, fixes worst first:

earshot critique video.mp4

The honest limits

It cannot judge taste, emotion, or speech content, and busy mixes blur its tags. Very short sounds read weakly. It compares against launch-film references, so a fix that fights your format is yours to overrule. Listen once yourself before you post.
