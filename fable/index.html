Claude Fable 5.2 writes code. The code becomes video.

Claude Fable 5.2 — Anthropic’s animation model, launched 9 November 2026 — does not generate video. It writes the code that renders to video: a Three.js scene, a Remotion project, a Blender script. You describe the video. It writes the program. Your browser renders the MP4. This guide has the cost, the proof, and the exact steps to try it.

The cost, first — because it is not free. Fable 5.2 is not on the Free plan. On the API it costs $8 per million input tokens and $40 per million output tokens (model id claude-fable-5-2). In the Claude apps, Fable on a Pro plan runs on pay-as-you-go usage credits; on Max ($100/month) and Ultra ($200/month), Fable can use up to 50% of weekly limits. The launch-week offer — Fable inside weekly limits at no extra cost — ended 16 November 2026. A short film in independent tests cost $1.40–$4.25 in API tokens; a full game built in one run cost about $550. Code-made films burn a lot of output tokens, and a long render-and-review loop adds up fast.

What Fable actually does

Anthropic’s own wording: Fable 5.2 “creates simulations, animations, and educational videos with sound in code.” The model only outputs text — so the animation is an HTML page, a Three.js scene, a Remotion or HyperFrames project, or a Blender Python script that plays in a browser and renders to MP4. It does not draw frames the way a video model does.

That is the whole trick, and it is why the results look different from AI video:

  • Everything is editable. The type, the colours, the timing, the camera — all of it is code you can open, change and re-render.
  • Nothing is hallucinated twice. A video model redraws every frame; Fable’s code renders the same scene deterministically.
  • It can look at its own work. Fable reads charts and figures far better than earlier models (73.4% on Anthropic’s Chartography test, vs 64.4% for Opus 5.5), so the render-review-fix loop actually works: render the frames, look at them, fix the code.

Anthropic still recommends Opus 5.5 as the daily driver and Fable for the most ambitious, open-ended work — or as an advisor over smaller models. Fable costs twice Opus per token ($8/$40 vs $4/$20), so use it where the creative choices matter, not for routine edits.

Try it (4 steps)

1
Update Claude Code to version 2.1.321 or newer. Fable needs a paid Claude plan (Pro, Max, Ultra, Team or Enterprise) — see the cost box at the top.
2
Switch models inside Claude Code:
/model fable
3
Describe the video you want — the subject, the style, the length, the camera. Try one of the starter prompts below.
4
Render what it writes. Fable hands you code: open the HTML file in a browser, run the Remotion project, or run the Blender script. The MP4 comes out of your render, not out of the model. Watch it, tell Fable what to fix, re-render.

3 starter prompts

1. Kinetic typography explainer (the format that won Fable’s test films):

“Make a 30-second kinetic-typography explainer as a single HTML file. Topic: [your topic]. Big bold type, one idea per shot, words landing on the beat, dark background, one accent colour. Render it to MP4.”

2. Data chart, animated:

“Animate this data as a 20-second chart video in Three.js: [paste 4–6 numbers]. Bars grow in one by one, the biggest number lands last with a count-up, clean light background, labels always readable.”

3. A 3D scene from one sentence:

“Build a 15-second 3D scene in Three.js: a [subject] rotating slowly, orbit rings around it, warm light, cream background. Camera pushes in slowly the whole time. Export the render as MP4.”

Honest limits

  • It costs real money per film. Short films ran $1.40–$4.25 in tests; a long review loop costs more. Set a budget before you start iterating.
  • The reel’s demos are ours, not Fable’s. The rotating cell and the iso city in the video are Three.js scenes we built to show what “code becomes video” means — the footage is real code rendering live in a browser, but Fable did not write those scenes. The proof numbers above are Fable’s real public results.
  • You still have to render. Fable writes code; the MP4 comes from your browser, Remotion or Blender. If the code has a bug, you see a broken frame — paste the error back and it fixes it.
  • Quality varies by prompt. In the 7-film independent test, Fable won 4 outright (kinetic typography, model launch, product launch, open brief) and lost pixel-art to Opus. Vague briefs get vague films — name the style, the length and the camera.
  • Not for photoreal people. Fable’s strength is motion graphics, explainers, data, 3D scenes and games. For photoreal humans and lifestyle footage, a video model is still the right tool.
