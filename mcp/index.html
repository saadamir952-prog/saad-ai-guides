Claude built this edit in my timeline.

Most AI editors hand you a finished file you can't touch. VN's Auto Edit MCP server lets Claude Code build the edit on VN's timeline — so after the AI pass you can still trim a clip, fix a caption word, or balance the audio by hand. Four steps.

The setup in one line: open Auto Edit, toggle MCP Server on, copy the setup prompt into a new Claude Code chat, then ask in plain words.

The cost — read this first

Claude Code needs a paid Claude plan or API credits — that is the one paid part. VN is a free download with a free tier and VN Pro is optional for this setup. Before you post with it, check on your own free VN install that the Auto Edit MCP toggle is available without VN Pro.

What you need

VN Video Editor on macOS or Windows (desktop flow; keep VN open while the agent is connected), Claude Code, and your own clips. The VN tutorial shows VN 1.7.0+ on Mac / 0.6.4+ on Windows — re-check the current version requirement in the app.

The 4 steps

1. Turn the switch on. Download and open VN, go to Auto Edit, toggle on MCP Server. Keep VN open while your agent is connected.

2. Copy the setup prompt. In the VN app (Auto Edit → Config), copy the setup prompt/configuration for Claude Code.

3. Connect. Start a new Claude Code chat, paste the setup prompt, and confirm VN is connected.

4. Ask in plain words. Type what you want — the official example prompt:

Turn today's clips into a 30-second travel vlog.

After the AI pass — the part that matters

The timeline stays yours: trim and rearrange clips, refine captions, adjust audio, or ask the agent for another pass. It will not nail every caption word — click the caption and fix the word yourself. That hand fix is faster than explaining it.

Troubleshooting

Agent cannot connect: keep VN open with MCP Server enabled in Auto Edit → Config, copy the current configuration again, then restart the agent or start a new session.

Not fully offline: VN runs a local MCP server, but your connected agent may still need internet access. No separate CLI install is needed for the Auto Edit flow.
