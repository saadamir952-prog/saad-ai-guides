The 5 steps

  1. Set up the folder — The only manual step: copy your camera clips into one folder and open Claude Code in it. Everything after this is Claude's job.
  2. Transcribe everything — Claude transcribes every clip with a timestamp for every word — the transcript is what the whole edit is decided on.
  3. Match the voices — In multi-person clips, Claude separates your voice from the others — so the edit keeps the takes where YOU are speaking.
  4. Build the JSON cut list — The edit lives in one plain JSON file — clip + start + end per cut. Change a number, re-render; no need to ask the AI to start over.
  5. Cut, caption, export — ffmpeg cuts and stitches the clips from the cut list, SRT subtitles go on top — then you watch the whole thing before posting.
