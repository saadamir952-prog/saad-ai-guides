Before you install anything

You need Claude Code first: a paid Claude plan, then install Claude Code from claude.com/product/claude-code. A Claude Code skill is just a folder of instructions (a SKILL.md file) that teaches Claude how to do one job. Installing a skill = putting that folder where Claude Code can find it, usually ~/.claude/skills/. After that, you just talk to Claude in plain English and it does the job.

1. Ghost Editor — it cuts your mistakes

Raw talking-head in, best takes kept, mistakes cut, captions that never cover your face. A skill that edits talking-head reels in 19 styles and renders on your Mac.

  • Repo: github.com/kurbaitaev/ghost-editor — MIT, 622 stars (19 Nov 2026)
  • Best for: talking-head reels, podcasts, any video where you talk to camera and want the ums, pauses and bad takes gone.
git clone https://github.com/kurbaitaev/ghost-editor ~/.claude/skills/ghost-editor
# then follow its docs/INSTALL.md inside Claude Code

What to say to Claude: “Edit this talking-head clip: cut the silences and mistakes, keep the best takes, add captions that never cover my face.”

Know before you install: about 4 GB of disk — the install sets up ffmpeg, Node, Python, Whisper and OpenCV. A free Gemini API key is optional for its B-roll check (the frames it checks go to Google; without the key, that check is simply skipped). An ElevenLabs key is only needed if you want its explainer narrator voice.

2. FFmpeg Skill — the technical jobs, on your computer

42 editing tools inside Claude: cut silences, add subtitles, crop vertical, fix audio, convert formats. Runs entirely on your own computer — no cloud, no upload, no API keys.

  • Repo: github.com/kajisho5/ffmpeg-skill — MIT, 8,086 stars (19 Nov 2026)
  • Best for: the boring-but-necessary jobs — silence cuts, vertical crops, subtitles, audio cleanup — done locally and verified after every step.
# FFmpeg itself, once (Ubuntu/Debian shown; macOS and Windows in the repo's install table)
sudo apt install ffmpeg

# Install the skill for Claude Code (Cursor: --cursor, Codex: --codex, all three: --all)
npx ffmpeg-skill

What to say to Claude: “Cut the silences, crop this to vertical 9:16, and add subtitles.”

3. Claude Shorts — one long video, many captioned clips

Give it a long video; it finds the best moments and cuts captioned vertical clips out of it. The repurposing machine: one podcast or stream becomes a week of shorts.

  • Repo: github.com/AgriciDaniel/claude-shorts — MIT, 435 stars (19 Nov 2026)
  • Best for: turning long videos (podcasts, streams, talks) into short vertical clips with captions.
git clone https://github.com/AgriciDaniel/claude-shorts.git
cd claude-shorts
bash setup.sh
bash install.sh

What to say to Claude: “Cut the 5 best moments from this long video into captioned vertical shorts.”

4. OpenMontage — it copies any edit you love

Show it a reel you love; it studies the hook, pacing and edits, then makes yours the same way. The most powerful of the four — and the one with the biggest honest asterisk.

  • Repo: github.com/OpenMontageInc/OpenMontage — AGPL-3.0, 81,616 stars (19 Nov 2026)
  • Best for: rebuilding a reel in a style you admire — same hook structure, same pacing, your footage.
git clone https://github.com/OpenMontageInc/OpenMontage.git
cd OpenMontage
make install

Needs: Python 3.10+, FFmpeg, Node.js 22/24/26, and an AI coding assistant (Claude Code, Cursor, Copilot, Windsurf or Codex). Full requirements are in the repo README.

What to say to Claude: “Study this reel’s hook and pacing, then rebuild my clip the same way.”

The honest asterisk: the free path uses stock footage — the agent builds a corpus from free stock footage and open archives and edits real motion clips into a timeline. Paid AI-clip paths via fal.ai exist (their demo short cost $1.33). Use the free stock path unless you deliberately choose to pay.

The workflow, start to finish

  1. Get Claude Code — paid plan ($20/month, or $17/month billed annually). The skills are free; the seat is not.
  2. Install the skill you need with the commands above — start with one, not all four.
  3. Drop in your clip and describe the edit in plain English, like the examples above.
  4. Watch the result before you post. If a cut feels wrong, tell Claude what you see and it fixes it. It drafts, you approve.
