## Setup checklist (10 minutes, once)

1. Install Claude Code and sign in with your Claude plan.
2. Make one folder for your videos, e.g. `my-videos`.
3. Put one phone clip in the folder. Vertical (9:16) is best.
4. Open Claude Code inside that folder.

## The first prompt (copy-paste)

Paste this, change nothing:

> Edit this like a finished reel: cut the pauses, add captions, level
> the sound, export vertical.

That one sentence does four jobs: cuts the dead air, burns word
captions, levels the audio to platform loudness, and exports a
1080×1920 file ready to post. In our test run, an 11.8-second raw
clip came back as a 9.1-second finished reel: 3 pauses cut, 27
caption words, sound leveled.

## What to shoot first (shot list)

Shoot these three, 5–10 seconds each, phone vertical, good light:

1. **Your face, one sentence.** Say the one thing your video is about.
2. **Your hands doing the thing.** The product, the tool, the food.
3. **The result.** The finished thing, close up, held still 3 seconds.

Talk like you talk. Pauses are fine — the edit cuts them.

## The honest limits

Your first video will look finished. It won't make you a filmmaker
overnight, and it can't fix a clip that's too dark or too quiet.
Shoot the result shot well and the rest follows.
